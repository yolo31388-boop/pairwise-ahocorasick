实现一个 AC 自动机（Aho-Corasick）多模式匹配引擎，只用 Python
标准库。

背景：ac.py 是骨架（ACAutomaton 类方法 raise NotImplementedError），
tests/test_ac.py 是验收测试。

需求（feature，按 AC 自动机论文核心语义）：
1. build(patterns)：所有模式插入 Trie（根节点 0，children 按字符）；
   叶子节点 output 记录模式索引
2. BFS 构建 fail 指针：
   - 根的孩子 fail = 根
   - 其他节点：沿父节点 fail 链找含该字符的最深前缀，找不到回根
   - 节点 output 沿 fail 链传递（output 继承，使 fail 可达的
     模式在匹配时也能命中）
3. find(text)：线性扫描 O(len(text))：
   - 当前字符不在 children 时沿 fail 回退（根不回退）
   - 匹配节点 output 中的每个模式 -> 记录 (pattern, start, end)，
     start = i - len(pattern) + 1
   - 返回全部命中（含重叠、跨 fail 链的更长模式）
4. stats() -> {patterns, nodes, depth}

验收：
- python -m pytest tests/test_ac.py -q 全绿
- 覆盖：单模式/多模式重叠（ushers 的 she+he）/abab 的 ab+bab
  三重命中/经典 ushers 四模式（含跨 fail 链的 hers）/重复模式
  各命中一次/单字符/无匹配/空文本/统计字段/长文本线性

要求：
- 只 import 标准库；必须真实构建 Trie + fail 指针并沿其匹配
  （禁止对每个模式单独 str.find 再汇总，长文本用例会验证
  线性复杂度）；别改测试
